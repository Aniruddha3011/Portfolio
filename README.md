# Professional Portfolio - Aniruddha

A modern, responsive portfolio website showcasing my journey as a Computer Engineering student and aspiring Software Developer.

## 🚀 Features

- **Modern Design**: Clean, professional layout with gradient accents and smooth animations
- **Responsive**: Fully responsive design that works seamlessly on desktop, tablet, and mobile devices
- **Interactive Elements**: Smooth scrolling navigation, hover effects, and animated skill bars
- **Project Showcase**: Detailed project cards with technology tags and links
- **Contact Form**: Functional contact section for professional inquiries
- **Performance Optimized**: Lightweight and fast-loading with CDN resources

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for accessibility and SEO
- **Tailwind CSS**: Utility-first CSS framework for rapid styling
- **Font Awesome**: Professional icons for visual enhancement
- **AOS (Animate On Scroll)**: Smooth scroll animations
- **Vanilla JavaScript**: Interactive functionality and smooth user experience

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Local web server (optional, for development)

### Installation & Setup

1. **Clone or Download** the project files to your local machine
2. **Navigate** to the project directory
3. **Open** `index.html` in your web browser

### Using a Local Server (Optional)

For development purposes, you can use a local server:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (if you have http-server installed)
npx http-server

# Using PHP
php -S localhost:8000
```

Then open `http://localhost:8000` in your browser.

## 🎯 Customization

### Personal Information
Update the following sections in `index.html`:

1. **Personal Details** (Hero section):
   - Name and title
   - Introduction text
   - Social media links

2. **Contact Information** (Contact section):
   - Email address
   - LinkedIn profile URL
   - GitHub profile URL

3. **Project Details** (Projects section):
   - Project descriptions
   - Technology tags
   - Repository and demo links

### Color Scheme
The portfolio uses a purple gradient theme. To customize:
- Modify the CSS variables in the `<style>` section
- Update gradient colors in `.gradient-text` and `.hero-gradient` classes
- Adjust hover states and accent colors

### Adding New Projects
To add new projects:
1. Copy an existing project card structure
2. Update the content with your project details
3. Add appropriate technology tags
4. Update links to repositories/demos
